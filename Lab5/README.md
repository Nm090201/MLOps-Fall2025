# GCP Terraform Image Hosting Project
!(image.png)
This Terraform project deploys a simple web application on Google Cloud Platform that hosts and displays an image through a VM running Nginx.

# What It Does
Creates a complete infrastructure that:
- Stores an image in a Google Cloud Storage bucket
- Deploys a VM instance with Nginx web server
- Configures firewall rules for HTTP access
- Displays the image on a public web page

# Prerequisites
- Terraform installed
- Google Cloud Platform account
- GCP Service Account credentials
- An image file to upload
