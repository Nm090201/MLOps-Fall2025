# Experiment Tracking with MLflow & Weights & Biases 

Experiment tracking records and organizes machine learning experiments, capturing:

Model parameters and hyperparameters
- Performance metrics (accuracy, loss, AUC)
- Training artifacts (models, plots, datasets)
- Code versions and environment details

This enables teams to compare models, reproduce results, and collaborate effectively.

MLflow Overview
- Open-source platform for managing the complete ML lifecycle.

Key Features
- Log parameters, metrics, and models
- Compare multiple experiments
- Model registry with versioning
- Deploy models to production
- Self-hosted or cloud-based

Best For
- Production ML pipelines
- Traditional ML models (scikit-learn, XGBoost)
- Teams needing full control over infrastructure


TensorFlow + MLflow Integration
TensorFlow works seamlessly with MLflow for deep learning experiments.

What You Can Track
- Training/validation metrics per epoch
- Model architecture and weights
- Learning rate schedules
- TensorBoard visualizations
- Model checkpoints

Use Cases
- Image classification
- NLP models
- Neural network hyperparameter tuning


Weights & Biases (W&B) Overview
Cloud-based experiment tracking platform designed for deep learning.

Key Features
- Real-time interactive dashboards
- Automated hyperparameter sweeps
- Team collaboration tools
- Beautiful experiment reports
- System metrics (GPU, memory)

Best For
- Deep learning research
- Teams needing collaboration
- Real-time monitoring
- Advanced visualization needs
